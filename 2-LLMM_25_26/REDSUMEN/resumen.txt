📦 1. MODELO DE CAJA

Todo elemento es una caja con:

content → lo que hay dentro (texto, imagen…)

padding → espacio interior entre contenido y borde

border → línea que rodea el elemento

margin → espacio exterior entre ese elemento y otros

Propiedades:

width → define el ancho.

height → define el alto.

margin → espacio exterior.

padding → espacio interior.

border-width → grosor del borde.

border-style → tipo de borde (solid, dashed, dotted…).

border-color → color del borde.

border → versión resumida de las tres anteriores.

border-radius → redondea las esquinas.

----------------------------------------------------------------------------------------------------

🎨 2. COLORES Y FONDOS
Texto

color → cambia el color del texto.

Fondo

background-color → color de fondo.

background-image → imagen de fondo.

background-repeat → controla si la imagen se repite.

background-position → posición de la imagen.

background-attachment → fija o no la imagen al hacer scroll.

opacity → nivel de transparencia del elemento (0 a 1).


----------------------------------------------------------------------------------------------------


📍 3. POSICIONAMIENTO

position → define cómo se coloca el elemento:

static → normal.

relative → se mueve respecto a su posición original.

absolute → se posiciona respecto a su contenedor.

fixed → se queda fijo aunque haya scroll.

top, bottom, left, right → desplazan el elemento.

float → coloca el elemento a izquierda o derecha.

clear → evita que un elemento se coloque junto a uno flotante.


----------------------------------------------------------------------------------------------------


👁 4. VISUALIZACIÓN

display → cambia cómo se comporta el elemento:

block → ocupa toda la línea.

inline → se comporta como texto.

none → desaparece completamente.

visibility → oculta pero mantiene el espacio.

z-index → controla qué elemento queda encima.

overflow → controla qué pasa si el contenido se sale (scroll, hidden…).


----------------------------------------------------------------------------------------------------


✍ 5. TEXTO

font-family → tipo de letra.

font-size → tamaño.

font-weight → grosor (negrita).

font-style → cursiva.

font-variant → mayúsculas pequeñas.

font → versión resumida.

text-align → alineación horizontal.

line-height → espacio entre líneas.

text-decoration → subrayado, tachado…

text-transform → convierte texto en mayúsculas/minúsculas.

text-shadow → sombra al texto.

letter-spacing → espacio entre letras.

word-spacing → espacio entre palabras.

text-indent → sangría en primera línea.

white-space → controla cómo se interpretan los espacios.

Fuentes externas

@font-face → permite usar fuentes personalizadas.

@import → importa hojas de estilo o fuentes.


----------------------------------------------------------------------------------------------------


📋 6. LISTAS

list-style-type → cambia la viñeta (disc, square, decimal…).

list-style-position → posición de la viñeta.

list-style-image → usa una imagen como viñeta.

list-style → versión resumida.


----------------------------------------------------------------------------------------------------


📊 7. TABLAS

caption-side → posición del título.

empty-cells → muestra u oculta celdas vacías.

border-collapse → une o separa bordes.

border-spacing → espacio entre celdas.

table-layout → cómo se calcula el ancho (auto o fixed).


----------------------------------------------------------------------------------------------------


📝 8. FORMULARIOS

Pseudo-clases:

:valid → cuando el campo es válido.

:invalid → cuando no lo es.

:required → campos obligatorios.

:in-range / :out-of-range → dentro o fuera del rango permitido.

:read-only → solo lectura.

Propiedad importante:

box-sizing → cambia cómo se calcula el tamaño:

content-box → ancho sin contar padding/borde.

border-box → ancho incluyendo padding y borde.


----------------------------------------------------------------------------------------------------


✨ 9. EFECTOS CSS3
Sombras

text-shadow → sombra en texto.

box-shadow → sombra en cajas.

Degradados

linear-gradient() → degradado en línea.

radial-gradient() → degradado circular.

Transformaciones

transform:

translate() → mueve.

rotate() → rota.

scale() → agranda o reduce.

skew() → deforma.

Transiciones

transition → hace cambios suaves entre estados.

transition-duration → cuánto dura.

transition-delay → cuándo empieza.

Animaciones

@keyframes → define los pasos.

animation → aplica la animación.

animation-duration → duración.

animation-iteration-count → repeticiones.

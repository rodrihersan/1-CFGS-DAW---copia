EJERCICIO 3

172.25.0.0 tipo B (ya que va de 128 a 191) con mascara de /16 (255.255.0.0)

Necesitamos 3 subredes, una para los primeros 150 equipos, otra para 40 y otra para 90.

Para los 150 equipos hacemos 2^n, en este caso seria 2^8 que da 256 (2^7 da 128 y nos quedamos cortos)
Entonces necesitamos 8 bits para host de la mascara de red, por lo que quedaría la mascara como 255.255.255.0 (/24)
La ip de red para estos 150 equipos quedaría como 172.25.0.0/24, la de broadcast 172.25.0.255 y las de host asignables 172.25.0.1-172.25.0.254

Para los 90 equipos hacemos 2^n, seria 7 que da 128
Se necesitan 7 bits para host. La ip seria entonces 172.25.1.0/25 (25 porque se resta 32-n  (7)) La ip se modifica (el 1) porque la anterior red esta destinada a los 150 equipos
De esta red, la ip seria 172.25.1.0, la de broadcast 172.25.1.127 (no es 255 porque no tenemos mascara /24, tenemos mascara /25, entonces la ip de la mascara sria /24 y luego 1000 0000. y las que se puede dar a dispositivos 172.25.1.1-172.25.1.126

Para los 40 equipos restantes hacemos 2^n que seria n=6 que serian 64 IPs disponibles. Necesitamos 6 de host, asi que sería 32-6 que son 26, la dirección ip red seria 172.25.1.128/26 que llegaría hasta 172.25.1.191 (broadcaste) y las ip asignables 172.25.1.129-172.25.1.190

EJERCICIO 4

172.30.0.0. ¿Cuántas subredes se podrían definir como máximo, si cada una tiene que alojar 130 dispositivos ? Razona la respuesta.
Ip tipo B. mascara 255.255.0.0 = 172.30.0.0/16

Queremos 130 dispositivos, asi que necesitamos saber cuantos bits de host debemos asignar, para ello hacemos 2^n que >= a 130 dispositivos, en este caso n=8 que seria 256. Para saber la mascara de subred hacemos 32-n en este caso 24

Sabiendo esto, tenemos que la red original es 16, y la subred es 24, asi que restamos esto y nos da 8, que haciendo 2^8 son las subredes que podemos tener. Que serian 256.

16 bits de red + 8 bits de subred + 8 bits de host = 32
Esos 8 bits del medio son los que puedes usar para numerar subredes distintas. 
Como cada bit puede ser 0 o 1, con 8 bits puedes hacer 2⁸ = 256 combinaciones distintas, es decir 256 subredes.
